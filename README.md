## 💻 Key OOP Paradigms Covered

- **Encapsulation & Abstraction**: Strict private visibility, public interfaces, accessor/mutator methods[cite: 4, 5].
- **Memory Safety & Resource Management**: RAII principles, heap allocation via `new`/`delete`, avoidance of dangling pointers[cite: 3, 7].
- **Polymorphism**:
  - *Compile-Time*: Function Overloading[cite: 2], Operator Overloading (Binary, Unary, Comparison)[cite: 1].
- **Friend Access Control**: Fine-grained access privileges via `friend` functions & classes without breaking abstraction boundaries[cite: 5].

## 🚀 Compilation & Execution Quickstart

### Prerequisites
Ensure you have GCC / MinGW installed with C++17 support:
```bash
g++ --version
```

### 1. Clone the Repository
```bash
git clone [https://github.com/vaibhav-maheshwari22/B125136.git](https://github.com/vaibhav-maheshwari22/B125136.git)
cd B125136
```

### 2. Compile and Run any Program
For example, compiling **Lab 6 - Question 1 (Distance Addition)**:
```bash
# Navigate to the target lab directory
cd "Lab 6"

# Compile with C++17 standard flags
g++ -std=c++17 q1.cpp -o q1

# Run the executable
# On Windows PowerShell:
.\q1.exe

# On Linux/macOS:
./q1
```
